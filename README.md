# End-to-End Traffic Steering in 5G Campus Networks

The thesis contribution is a controller that coordinates RAN and Core steering.

The target has one OAI CU, two DUs, two RFsim UEs, and a free5GC Core
with one I-UPF acting as ULCL and three PSAs connected to the DN.

The first runtime checkpoint uses one CU, one DU, one UE, and one UPF.
